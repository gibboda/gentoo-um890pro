# Kernel Management Guide

## Overview

This system supports two kernel installation modes:

1. **Single Kernel Mode** (default): Uses gentoo-kernel-bin for fast installation
2. **Dual Kernel Mode** (`INSTALL_DUAL_KERNEL="yes"`): Installs both a stable fallback and a custom tuned kernel

This guide focuses on the **Dual Kernel Mode** for maximum safety and flexibility.

## Dual Kernel Installation

When `INSTALL_DUAL_KERNEL="yes"` is set in the installer, two independent kernels are installed:

### Kernel A: Stable Binary Fallback
- **Package**: sys-kernel/gentoo-kernel-bin
- **Purpose**: Stable fallback kernel, never modified after initial install
- **Boot artifacts**:
  - `/boot/vmlinuz-<VERSION>-gentoo-dist`
  - `/boot/initramfs-<VERSION>-gentoo-dist.img` (auto-generated by dist-kernel)
  - `/boot/config-<VERSION>-gentoo-dist`
- **Modules**: `/lib/modules/<VERSION>-gentoo-dist/`
- **Example**: `6.12.58-gentoo-dist`

### Kernel B: Custom Tuned Kernel
- **Package**: sys-kernel/gentoo-sources
- **LOCALVERSION**: `-um890-tuned` (set via CONFIG_LOCALVERSION)
- **Purpose**: Optimized kernel for UM890 Pro hardware
- **Boot artifacts**:
  - `/boot/vmlinuz-<VERSION>-um890-tuned`
  - `/boot/initramfs-<VERSION>-um890-tuned.img` (generated by dracut for this kernel only)
  - `/boot/config-<VERSION>-um890-tuned`
- **Modules**: `/lib/modules/<VERSION>-um890-tuned/`
- **Example**: `6.12.58-um890-tuned`

Both kernels have **unique `uname -r` values**, ensuring no collisions in `/boot` or `/lib/modules`.

## Dracut Initramfs Configuration

The installer configures dracut for **per-kernel initramfs generation**:

```bash
# /etc/dracut.conf.d/10-versioned.conf
hostonly="yes"
hostonly_cmdline="no"
compress="zstd"
early_microcode="yes"

# Essential modules for UM890 Pro
add_drivers+=" amdgpu btrfs nvme "
add_dracutmodules+=" kernel-modules rootfs-block btrfs resume "
```

**Key behavior**: Each kernel gets its own initramfs with versioned naming:
- Kernel A: dracut auto-generates `/boot/initramfs-<VERSION>-gentoo-dist.img`
- Kernel B: `dracut --force --hostonly --kver <VERSION>-um890-tuned /boot/initramfs-<VERSION>-um890-tuned.img`

**NOT using** `dracut --regenerate-all` to avoid touching Kernel A.

## Boot Configuration with rEFInd

### rEFInd Auto-Detection

rEFInd automatically detects all kernels in `/boot` and creates boot entries:

```bash
# /boot/refind_linux.conf (created by installer)
"Gentoo (Btrfs subvol=@)"  "root=UUID=<UUID> rootfstype=btrfs rootflags=subvol=@ rw amd_pstate=active"
"Gentoo (Snapshot Recovery)"  "root=UUID=<UUID> rootfstype=btrfs rootflags=subvol=@snapshots/@-snapshot-latest rw amd_pstate=active"
```

### Boot Menu Entries

When dual-kernel is installed, rEFInd shows:
1. **Kernel B** (tuned): `/boot/vmlinuz-<VERSION>-um890-tuned` → First/default
2. **Kernel A** (fallback): `/boot/vmlinuz-<VERSION>-gentoo-dist` → Fallback option
3. **Snapshot Recovery**: Boot from latest snapshot

**Default behavior**: rEFInd auto-selects the most recent kernel (typically Kernel B).

## Rollback-First Guidance: Using Kernel A

If Kernel B (tuned) fails to boot or has issues:

### Step 1: Boot to Kernel A via rEFInd

1. Power on and wait for rEFInd boot menu (20 second timeout)
2. Use arrow keys to select **Kernel A** entry:
   - Look for: `vmlinuz-<VERSION>-gentoo-dist`
   - Example: `vmlinuz-6.12.58-gentoo-dist`
3. Press Enter to boot

### Step 2: Verify You're on Kernel A

```bash
uname -r
# Should show: <VERSION>-gentoo-dist
# Example: 6.12.58-gentoo-dist
```

### Step 3: Investigate Kernel B Issues

```bash
# Check system logs for kernel errors
dmesg | less
journalctl -xe  # systemd
tail -n 100 /var/log/messages  # OpenRC

# Check if Kernel B files are intact
ls -lh /boot/vmlinuz-*-um890-tuned
ls -lh /boot/initramfs-*-um890-tuned.img
ls -ld /lib/modules/*-um890-tuned
```

### Step 4: Rebuild or Remove Kernel B

```bash
# Option A: Rebuild Kernel B
cd /usr/src/linux
make clean
make -j$(nproc)
make modules_install
KVER=$(make kernelrelease)
install -m 0644 arch/x86/boot/bzImage "/boot/vmlinuz-${KVER}"
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"

# Option B: Remove Kernel B and stay on Kernel A
emerge --deselect sys-kernel/gentoo-sources
emerge --depclean
```

### Step 5: Reboot and Test

```bash
reboot
# Verify fixed kernel or confirm Kernel A works long-term
```

## Verification Checklist

After dual-kernel installation or updates, verify both kernels are properly installed:

### 1. Check Boot Artifacts

```bash
# Kernel A (gentoo-dist)
ls -lh /boot/vmlinuz-*-gentoo-dist
ls -lh /boot/initramfs-*-gentoo-dist.img
ls -lh /boot/config-*-gentoo-dist

# Kernel B (um890-tuned)
ls -lh /boot/vmlinuz-*-um890-tuned
ls -lh /boot/initramfs-*-um890-tuned.img
ls -lh /boot/config-*-um890-tuned
```

**Expected output**:
- Each kernel has vmlinuz, initramfs, and config files
- File sizes: vmlinuz ~10-15MB, initramfs ~15-30MB
- Timestamps show recent installation

### 2. Check Module Directories

```bash
# Kernel A modules
ls -ld /lib/modules/*-gentoo-dist

# Kernel B modules
ls -ld /lib/modules/*-um890-tuned
```

**Expected output**:
- Two separate directories with unique names
- Each contains: kernel/, modules.* files

### 3. Verify Unique Kernel Versions

```bash
# List all installed kernels
ls -1 /boot/vmlinuz-* | sed 's/.*vmlinuz-//'
```

**Expected output**:
```
6.12.58-gentoo-dist
6.12.58-um890-tuned
```

**Critical**: Each must have a unique suffix (`-gentoo-dist` vs `-um890-tuned`).

**Note**: Both kernels can be the same base version (e.g., both 6.12.58) because the LOCALVERSION suffix makes them unique. Different base versions (e.g., 6.12.58-gentoo-dist + 6.13.0-um890-tuned) are also supported.

### 4. Test Boot Both Kernels

```bash
# Current kernel
uname -r

# Reboot and select alternate kernel from rEFInd menu
# Verify it boots successfully
```

### 5. Verify Initramfs Contents

```bash
# List contents of Kernel B initramfs
lsinitrd /boot/initramfs-*-um890-tuned.img | head -20
```

**Expected**: Should show kernel modules, firmware, and boot scripts.

### 6. Check rEFInd Detection

```bash
# rEFInd should detect both kernels
ls -l /boot/EFI/refind/refind.conf
cat /boot/refind_linux.conf
```

### 7. Verify Dracut Configuration

```bash
cat /etc/dracut.conf.d/10-versioned.conf
```

**Expected**: Per-kernel settings, NOT generic `initramfs.img`.

## Single Kernel Mode (Default)

When `INSTALL_DUAL_KERNEL="no"` (default), only one kernel is installed:

### Binary Kernel Mode (`USE_BINARY_KERNEL="yes"`)
```bash
# Package: sys-kernel/gentoo-kernel-bin
# Boot files: /boot/vmlinuz-<VERSION>-gentoo-dist
#             /boot/initramfs-<VERSION>-gentoo-dist.img
```

### Source Kernel Mode (`USE_BINARY_KERNEL="no"`)
```bash
# Package: sys-kernel/gentoo-kernel
# Boot files: /boot/vmlinuz-<VERSION>-gentoo
#             /boot/initramfs-<VERSION>-gentoo.img
```

**Switching from binary to source**: Use the `switch-to-source-kernel` helper script.

## Kernel Upgrade Workflow

### Upgrading Dual Kernels

When a new kernel version is released:

#### Option A: Upgrade Only Kernel A (Safest)
```bash
# Update stable fallback kernel
sudo emerge --sync
sudo emerge -u sys-kernel/gentoo-kernel-bin
# Kernel B remains unchanged
```

#### Option B: Rebuild Kernel B with New Base
```bash
# Install new gentoo-sources
sudo emerge -u sys-kernel/gentoo-sources

# Select new kernel
sudo eselect kernel set gentoo-sources-<NEW_VERSION>

# Copy old config and rebuild
cd /usr/src/linux
cp /boot/config-*-um890-tuned .config
make olddefconfig

# Set LOCALVERSION again
scripts/config --set-str CONFIG_LOCALVERSION "-um890-tuned"
scripts/config --disable CONFIG_LOCALVERSION_AUTO

# Build and install
make -j$(nproc)
make modules_install
KVER=$(make kernelrelease)
install -m 0644 arch/x86/boot/bzImage "/boot/vmlinuz-${KVER}"
install -m 0644 .config "/boot/config-${KVER}"
install -m 0644 System.map "/boot/System.map-${KVER}"

# Generate initramfs for new kernel
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
```

#### Option C: Upgrade Both Kernels
```bash
# Upgrade both packages
sudo emerge -u sys-kernel/gentoo-kernel-bin sys-kernel/gentoo-sources

# Rebuild Kernel B with new version (see Option B)
```

### Single Kernel Upgrade

```bash
# For binary kernel
sudo emerge --sync
sudo emerge -u sys-kernel/gentoo-kernel-bin

# For source kernel
sudo emerge -u sys-kernel/gentoo-kernel
```

### After Upgrade

1. **Verify new kernels installed**:
   ```bash
   ls -lh /boot/vmlinuz-*
   ls -ld /lib/modules/*
   ```

2. **Reboot and test**

3. **Verify running kernel**:
   ```bash
   uname -r
   ```

4. **Keep old kernel for fallback** (already automatic with dual-kernel)

## Fallback Recovery

### Booting Kernel A (Fallback)

If Kernel B doesn't boot or has issues:

1. **At rEFInd boot menu** (appears automatically, 20-second timeout):
   - Use arrow keys to select Kernel A entry
   - Look for: `vmlinuz-<VERSION>-gentoo-dist`
   - Press Enter to boot

2. **Verify you're on Kernel A**:
   ```bash
   uname -r  # Should show: <VERSION>-gentoo-dist
   ```

3. **Investigate or fix Kernel B** (see "Rollback-First Guidance" above)

### Emergency Recovery

If neither kernel boots:

1. **Boot from Gentoo Live USB**

2. **Mount your system**:
   ```bash
   mount -t btrfs -o subvol=@ /dev/nvme0n1p2 /mnt/gentoo
   mount /dev/nvme0n1p1 /mnt/gentoo/boot
   mount --rbind /dev /mnt/gentoo/dev
   mount --rbind /proc /mnt/gentoo/proc
   mount --rbind /sys /mnt/gentoo/sys
   ```

3. **Chroot and fix**:
   ```bash
   chroot /mnt/gentoo /bin/bash
   source /etc/profile
   
   # Rebuild initramfs for the current kernel only
   dracut --force /boot/initramfs-$(uname -r).img $(uname -r)
   
   # Or reinstall kernel
   emerge -1 sys-kernel/gentoo-kernel-bin
   ```

4. **Reboot**

## Configuration Files

### Dracut Configuration

File: `/etc/dracut.conf.d/10-versioned.conf`

```bash
# Per-kernel initramfs configuration
hostonly="yes"
hostonly_cmdline="no"
compress="zstd"
early_microcode="yes"

# Essential modules for UM890 Pro
add_drivers+=" amdgpu btrfs nvme "
add_dracutmodules+=" kernel-modules rootfs-block btrfs resume "
```

**Key points**:
- Uses `hostonly="yes"` for smaller initramfs
- Automatically includes ZFS if installed
- Each kernel gets unique initramfs file

### rEFInd Configuration

File: `/boot/refind_linux.conf`

```bash
"Gentoo (Btrfs subvol=@)"  "root=UUID=<UUID> rootfstype=btrfs rootflags=subvol=@ rw amd_pstate=active"
"Gentoo (Snapshot Recovery)"  "root=UUID=<UUID> rootfstype=btrfs rootflags=subvol=@snapshots/@-snapshot-latest rw amd_pstate=active"
```

### Kernel Preservation Set

File: `/etc/portage/sets/kernels`

Contains kernel packages to preserve from depclean:
```bash
# Example entries
sys-kernel/gentoo-kernel-bin-6.12.58
sys-kernel/gentoo-sources-6.12.58
```

Edit manually to control which kernels are kept.

## Best Practices

### For Dual-Kernel Setup

1. **Keep Kernel A stable**: Don't rebuild or modify Kernel A (fallback)
2. **Test Kernel B thoroughly**: Always test after rebuilding tuned kernel
3. **Boot both kernels**: Verify both boot successfully after installation
4. **Document changes**: Keep notes of Kernel B customizations
5. **Use unique LOCALVERSION**: Never remove `-um890-tuned` suffix
6. **One initramfs per kernel**: Don't use `dracut --regenerate-all` unless necessary

### For Single-Kernel Setup

1. **Keep 2-3 versions**: Maintain old kernel versions for fallback
2. **Test before cleanup**: Always boot new kernel before removing old ones
3. **Use binary kernels**: Faster updates, less risk
4. **Document customizations**: If using source kernel, track config changes

### General

1. **Check boot artifacts**: After kernel updates, verify files in `/boot`
2. **Monitor boot menu**: Ensure rEFInd shows all kernels
3. **Verify module directories**: Check `/lib/modules` matches `/boot` kernels
4. **Keep snapshots**: Create Btrfs snapshot before major kernel changes

## Troubleshooting

### "Initramfs not found" Error

**Problem**: Kernel boots but can't find initramfs

**Solution**:
```bash
# Verify initramfs exists
ls -lh /boot/initramfs-*

# Regenerate for specific kernel
KVER=$(uname -r)
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"

# Or regenerate all (use with caution in dual-kernel setup)
dracut --force --regenerate-all
```

### "Kernel doesn't boot" After Update

**Problem**: New kernel fails to boot

**Solution**:
1. Boot Kernel A (fallback) from rEFInd menu
2. Check boot files exist:
   ```bash
   ls -lh /boot/vmlinuz-*-um890-tuned
   ls -lh /boot/initramfs-*-um890-tuned.img
   ```
3. Rebuild initramfs:
   ```bash
   KVER="<VERSION>-um890-tuned"
   dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
   ```

### "Modules not found" Error

**Problem**: Kernel boots but can't load modules

**Solution**:
```bash
# Check module directory exists
ls -ld /lib/modules/$(uname -r)

# Verify modules installed
ls /lib/modules/$(uname -r)/kernel/

# Reinstall modules
cd /usr/src/linux
make modules_install
```

### "Both kernels have same name"

**Problem**: Kernel A and B have identical filenames

**Solution** (for Kernel B):
```bash
cd /usr/src/linux

# Verify LOCALVERSION is set
grep CONFIG_LOCALVERSION .config
# Should show: CONFIG_LOCALVERSION="-um890-tuned"

# If not set, fix it:
scripts/config --set-str CONFIG_LOCALVERSION "-um890-tuned"
scripts/config --disable CONFIG_LOCALVERSION_AUTO
make olddefconfig

# Rebuild kernel with correct name
make -j$(nproc)
make modules_install
KVER=$(make kernelrelease)
install -m 0644 arch/x86/boot/bzImage "/boot/vmlinuz-${KVER}"
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
```

### "rEFInd doesn't show kernel"

**Problem**: Kernel files exist but don't appear in boot menu

**Solution**:
```bash
# Check rEFInd configuration
cat /boot/refind_linux.conf

# Verify kernel naming
ls -lh /boot/vmlinuz-*

# Check rEFInd scans /boot correctly
cat /boot/EFI/refind/refind.conf | grep scan

# Manually add if needed (rare)
# Edit /boot/EFI/refind/refind.conf
```

## Advanced Topics

### Customizing Kernel B

After dual-kernel installation, modify Kernel B for optimization:

```bash
cd /usr/src/linux
make menuconfig

# Important: Don't change LOCALVERSION
# Rebuild after changes
make -j$(nproc)
make modules_install
KVER=$(make kernelrelease)
install -m 0644 arch/x86/boot/bzImage "/boot/vmlinuz-${KVER}"
install -m 0644 .config "/boot/config-${KVER}"
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
```

### Adding ZFS Support to Initramfs

If you install ZFS after initial setup:

```bash
# dracut automatically includes ZFS if sys-fs/zfs is installed
# Rebuild initramfs for Kernel B
KVER="6.12.58-um890-tuned"
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
```

### Manual Kernel Build (Advanced)

For completely custom kernels outside the Gentoo package system:

```bash
# Download kernel source
cd /usr/src
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.12.58.tar.xz
tar xf linux-6.12.58.tar.xz
cd linux-6.12.58

# Configure with unique LOCALVERSION
cp /boot/config-*-gentoo-dist .config
make olddefconfig
scripts/config --set-str CONFIG_LOCALVERSION "-um890-custom"

# Build and install
make -j$(nproc)
make modules_install
KVER=$(make kernelrelease)
install -m 0644 arch/x86/boot/bzImage "/boot/vmlinuz-${KVER}"
install -m 0644 .config "/boot/config-${KVER}"
install -m 0644 System.map "/boot/System.map-${KVER}"
dracut --force --hostonly --kver "${KVER}" "/boot/initramfs-${KVER}.img"
```

### Switching Back to Single Kernel

To remove Kernel B and keep only Kernel A:

```bash
# Remove Kernel B package
emerge --deselect sys-kernel/gentoo-sources
emerge --depclean

# Remove Kernel B files
rm /boot/vmlinuz-*-um890-tuned
rm /boot/initramfs-*-um890-tuned.img
rm /boot/config-*-um890-tuned
rm -rf /lib/modules/*-um890-tuned

# Verify only Kernel A remains
ls -lh /boot/vmlinuz-*
```
