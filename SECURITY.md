# Security Policy

## Supported Versions

Security updates are provided only for the current minor release line.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

The current release is 1.3.0. Older 1.x releases do not receive security updates; please upgrade to 1.3.x.

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Report privately using one of these channels:

1. **GitHub private vulnerability reporting** (preferred):
   [Open a private advisory](https://github.com/gibboda/gentoo-um890pro/security/advisories/new)
2. **Email:** [gibboda@outlook.com](mailto:gibboda@outlook.com)

Please include the affected version (and install profile, if relevant), impact, and reproduction steps or a proof of concept.

You can expect an acknowledgement within 7 days. If the report is accepted, a fix will be developed privately and released with a security advisory when possible. If it is declined, you will be told why.
